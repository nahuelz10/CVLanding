# Portfolio web — Victor Nahuel Zalazar

## Cómo verlo
1. Descomprimí la carpeta.
2. Abrí `index.html` en tu navegador.
3. Para publicarlo, subí todos los archivos manteniendo la estructura de carpetas a Netlify, GitHub Pages o tu hosting.

## Personalizar LinkedIn
Abrí `script.js` y buscá:
`const LINKEDIN_URL = "";`
Pegá tu enlace entre las comillas. Ejemplo: `const LINKEDIN_URL = "https://www.linkedin.com/in/tu-usuario/";`

## Actualizar el CV
Reemplazá `assets/cv/cv-nahuel-zalazar.pdf` por tu CV nuevo, conservando exactamente ese nombre.
Si querés guardar varias versiones, agregalas en `assets/cv/` y modificá los enlaces de descarga en `index.html`.

## Idiomas y tema
- El botón `EN / ES` cambia entre español e inglés.
- El botón de luna/sol alterna modo claro y oscuro. La preferencia queda guardada en el navegador.

## Datos incluidos
El contenido de experiencia, educación, habilidades e idiomas se tomó del CV que compartiste. El enlace de LinkedIn no figura en el documento, por eso queda como campo editable. No se agregaron proyectos ni empleadores no mencionados en el CV.
